# Tipografía de marca

`NeueHaasUnicaPro-Black.woff2` se obtuvo del recurso tipográfico público que usa [damm.com](https://www.damm.com/themes/custom/dammc/components/asset-builds/fonts/NeueHaasUnicaPro-Black.woff2) para la familia CSS `Bottles Titles`.

El archivo se usa únicamente para reproducir la identidad visual solicitada en este prototipo de Damm Pulse. Antes de una distribución pública o comercial, el responsable del proyecto debe confirmar que la licencia de marca y tipografía cubre el despliegue previsto.
